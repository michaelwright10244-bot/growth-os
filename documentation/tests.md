| 用例 | 规则 | 预期行为（含拒绝情况） | 类型 | CI 门禁 |
|---|---|---|---|---:|
| 创建资料 | 正文、枚举、项目关联由后端校验 | 合法资料写入；空正文返回 `422` | FastAPI 集成测试 | 是 |
| 公开简历 | 仅公开项目可出现在简历 | 私密项目、资料正文和草稿不出现在 `/api/resume` | FastAPI 集成测试 | 是 |
| 草稿授权 | 模型只能读取本次选中的已授权资料 | 未授权或不存在 ID 返回 `422`，模型 client 不被调用 | 单元 + mock 集成测试 | 是 |
| 草稿状态 | 确认/拒绝不能删除原始资料 | 状态改变；materials 与 draft_sources 保持可读 | FastAPI 集成测试 | 是 |
| JSON 导入 | 坏文件不能损坏数据 | 校验失败不改旧库；成功导入使用临时文件原子替换 | storage 测试 | 是 |
| API 客户端 | UI 不依赖裸后端字段 | 成功解包；统一错误显示 request id；非 2xx 不静默失败 | 前端纯函数测试 | 是 |
| Agent 授权与并发 | 只使用已授权资料且一次只运行一个 | 未授权/重复资料返回 `422`；第二个任务返回 `409`；停止只影响对应进程组 | FastAPI + runner mock 测试 | 是 |
| Agent 重启恢复 | 未完成任务不能假装仍在运行 | 启动回收 `queued/running` 并标记失败；输出保持在 48k 字符以内 | storage + runner 单元测试 | 是 |

| 开发构建 | React、数据库索引与脚本仍可运行 | `uv run pytest`、`bun run build`、`bash -n start.sh stop.sh` 成功 | 构建/脚本检查 | 是 |
| 本地冒烟 | 服务端与前端监听正确端口 | `/health` 和页面返回成功，stop.sh 只停止项目进程 | 本地手工或 CI 容器 | 否 |

## 当前缺口

- 资料与公开状态的持久化规则目前只有 README 和 HTML 表述，尚无服务端实现或测试。
- AI 授权、LLM 输出校验、导入恢复是最高风险边界；功能未实现前不得以 UI 按钮模拟成功。
- `start.sh`/`stop.sh` 已覆盖双服务启动和停止；尚未在 CI 容器中执行真实端口冒烟，当前只做了本地人工冒烟。
